Nestlé Financial Performance Analysis

 Project Overview

This project focuses on analysing Nestlé's financial performance using SQL, Microsoft Excel and Power BI. It involves financial data preparation, SQL-based analysis and interactive dashboard development to understand key financial indicators and business performance.

 Project Objectives

- Analyse revenue, expenses and profitability.
- Examine financial performance across reporting years.
- Use SQL to extract and analyse financial data.
- Develop an interactive Power BI dashboard.
- Identify key financial findings and present them effectively.

 Tools & Technologies

- SQL: Data extraction, querying and analysis.
- Microsoft Excel: Data inspection and organisation.
- Power BI: Dashboard development and data visualisation.

 Key Financial Metrics

Metric| Value
Total Revenue| 433.56K
Total Expenses| 348.14K
Profit Before Tax (PBT)| 88.80K
Profit After Tax (PAT)| 67.07K
Revenue Growth| 14.62%
PAT Margin| Approximately 15%

 Key Financial Findings

- Total revenue reached 433.56K.
- Revenue growth was reported at 14.62%.
- Total expenses amounted to 348.14K.
- Profit Before Tax stood at 88.80K.
- Profit After Tax reached 67.07K.
